KNALLHART SERVIERT – GEÄNDERTE DATEIEN

Diese ZIP enthält nur die Dateien, die für die neue Darstellung von Platz/Punkten
und die zusätzliche Spalte „Ø Punkte“ geändert wurden.

So übernimmst du sie:
1. ZIP entpacken.
2. In deinem GitHub-Repository jeweils zum gleichen Ordnerpfad gehen.
3. Die vorhandene Datei durch die Datei aus dieser ZIP ersetzen.
4. Änderungen committen.

Wichtig:
- Die Ordnerstruktur in der ZIP entspricht der Ordnerstruktur im Repository.
- Es ist keine Datenbankmigration nötig.
- Die .patch-Datei brauchst du für diese Methode nicht.
